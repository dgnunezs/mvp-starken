# MVP Starken

Proyecto vinculado a GitHub y base de datos en **Supabase**.

## Configuración de Entorno

1. Copia `.env.example` a `.env` (si aún no existe):
   ```bash
   cp .env.example .env
   ```
2. Las variables de conexión a Supabase están configuradas en `.env`:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
   - `SUPABASE_PROJECT_ID`
